USB Ethernet Fix for TV

Install the app

The app isn't in the Play Store. You install it on the TV with the free Downloader app, which takes about two minutes.

On the TV

  1. Install Downloader.
    Open the Play Store on the TV, search for Downloader (by AFTVnews) and install it.
  2. Let Downloader install apps.
    In the TV's Settings, find Unknown sources (under Apps, or Privacy, then Security & restrictions) and turn it on for Downloader. Downloader also offers to take you there the first time it installs something.
  3. Type the address.
    Open Downloader and type hugelevin.github.io/usb-ethernet-fix/get, then select Go. The latest version downloads.
  4. Install.
    Select Install when the TV asks. When it finishes, select Done, then delete the downloaded file if Downloader offers it.
  5. Open USB Ethernet Fix from your apps and follow Get started.

Updating

Repeat steps 3 and 4. The new version installs over the old one and keeps your settings.

Direct download

On a computer or phone: all versions and release notes. To install from a computer over ADB: adb install -r usb-ethernet-fix-tv.apk.

The app asks for two things Android requires for what it does: USB access (to drive the adapter) and a VPN connection (the only way an app may carry the TV's network traffic). Your traffic goes from the TV through the adapter to your router and nowhere else. The app has no ads and collects nothing.
